# Bot Office · Gulf Air terminal, Bahrain International Airport
Open `index.html` (double-click works offline) or serve the folder with
`python3 -m http.server`. Files: `index.html` (scene + UI), `data.json` (real bot
activity), `embed.py` (copies data.json inline), `lib/` (three.js r147 + OrbitControls,
bundled for offline use), `refresh.md` (how to update the data).
